## 这次修正

- D 从右支架**底部零点**沿支架量起；不再把它当成转轴以上的附加高度。
- 图上标出底部 `0`、D 尺寸线与共同转轴 `O`。
- B 限位杆的下端就在 O，与 A 臂完全共轴。
- 橡皮筋从 E 经过 D 后的回绳严格竖直，图中有 `90°` 标记。
- 共轴支架版中，B 会带动右支架底座绕 O；D 拖动沿支架方向计算。原站版中右支架固定。
- 回绳下端锚点在设置时沿底座导轨与销点水平对齐，随后锁定。这样即使支架倾斜，回绳也保持与地面成 90°。这个理想化约束是为满足本轮要求明确加入的，不冒充原站内部模型。
- 图形和受力计算使用同一个机构几何函数，避免只移动图片、计算位置仍保持旧值。

## 操作

直接拖动黄色臂，松手即可发射。要只调位置，取消“拖动黄色投射臂，松手即发射”。A / B 也支持圆弧拖动、大滑块、数字输入与 ±1°；C / E 沿臂拖动，D 沿支架拖动。

| 变量 | 范围 |
|---|---|
| A 释放角 | 100–185° |
| B 开火角度 | 90–110° |
| C 球杯位置 | 200–300 mm |
| D 距支架底部的销位置 | 100–200 mm |
| E 绳挂点位置 | 100–200 mm |

D 的测量零点是 0，可调区间保留 100–200 mm。A 不能低于 B；A=B 时尚未上弦。调整限位 B 时尚未上弦的臂随限位移动。

## 三目标与 DOE

近 / 中 / 远默认 250 / 300 / 425 cm，可以设置 70–700 cm 内的递增目标。公差 **±15 cm，含上下边界**。实际落点按物理模型计算，不强制裁剪至目标范围。

探索和确认验证分开记录。确认默认连续 10 次，可设 2–30 次；锁定参数和目标，支持完成本发后停止。成绩只统计每个目标最近一组同设置验证，旧目标和历史设置不覆盖。

保留 PPT 教学路线：课堂三因子 A/C/D，B=110°、E=200 mm 固定；19 次全因子加中心点；25 次表面中心设计；效应、交互、响应拟合、三个目标的建议设置以及独立确认验证。也保留五因子全因子与半分数。

物理假设和验证见 [PHYSICS_NOTES.md](PHYSICS_NOTES.md)。程序是明确假设下的教学模型，图形独立重绘，不是原设备的标定数字孪生。
