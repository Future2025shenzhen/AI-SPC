# 投射器 DOE 三目标竞赛版

投射器 DOE 三目标竞赛版

打开方式
将 DOE_Catapult_Competition.html 保存到电脑，用 Chrome 或 Edge 打开即可。
单个 HTML，无网络依赖，不安装软件。中文优先使用 Microsoft YaHei（微软雅黑）；
电脑未安装该字体时浏览器会回退到本机中文字体。本程序不包含微软雅黑字体文件。

目标与验证
默认近 / 中 / 远目标为 250 / 300 / 425 cm，可改为 70～700 cm 范围内的有序数值。
公差固定为 ±15 cm，含上下边界。点击目标卡切换要打的目标。
鼠标在图片上拖动 A / B 旋钮、C 球杯、D 定位销、E 绳挂点，或使用左侧输入框。
释放角范围 100～185°；开火角度范围 90～110°。
“探索发射”用于调试；“验证当前目标”按当前参数连续发射，默认 10 次，可改为 2～30 次。
验证期间目标、波动和参数锁定；“完成本发后停止”保留已完成结果。
目标板中绿色圆点是命中，红色菱形是未命中。点击落点查看详细距离和偏差。
验证成绩按每个目标最近一次同设置验证组统计，不混合探索数据。
修改目标后，历史记录仍保存原目标与公差；旧目标验证会明确标注。

参考 PPT 的课堂路线
1. 默认三因子设计：A 释放角 140/180°，C 球杯高度 200/300 mm，D 定位销高度 100/200 mm；
   B 开火角度固定 110°，E 弹力绳位置固定 200 mm。
2. 2³ 全因子：8 个角点组合，每组合重复 2 次，增加 3 次中心点，共 19 次。
3. 表面中心设计：上述 19 次加 6 个轴向点，共 25 次，适于拟合三因子二次响应。
4. 完成后查看效应、交互作用及拟合模型。点击优化按钮为三个目标生成建议设置。
5. 载入建议设置回到实验台，进行独立确认验证。预测在公差内不等于实际必定命中。
6. 数据可导出 CSV，在 Minitab / JMP 中继续做正式 ANOVA、失拟及残差诊断。

重要说明
参考《001 投射器试验竞赛小结.ppt》的教学流程，未照搬原设备响应方程。
PPT 的部分 mm/cm 标题不一致，且使用 ±20 示例；本程序按用户要求统一 cm、±15。
本模拟为教学模型，投射距离以平滑函数映射到 70～700 cm；不是原设备的校准模型。
训练 R² 和残差误差仅描述当前拟合，不是未来命中保证。
数据仅在当前网页内存中保存，刷新/关闭会清空。请及时导出落点 CSV 和验证汇总 CSV。
