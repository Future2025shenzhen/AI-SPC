# 投射器实验设计与分析

Catapult Design of Experiments & Analysis。下载 ZIP、解压，打开 `DOE_Catapult_Reference_Layout.html`，无需安装或联网。`DOE_Catapult_Competition.html` 为相同兼容入口。

- 中文微软雅黑；深蓝工业风；投射器右侧面板已移除，因子面板在投射器下方横排，窄屏自动换行。
- A 球种（0 乒乓球、1 高尔夫球）；B 释放角；C 开火角；D 球杯高度；E 定位销刻度；F 弹力绳挂点。E 为 0–200 格，1 格=1.22 mm；200 格距立臂上端 20 mm，图像和物理共用此比例。
- 拖黄色臂、松手发射；点击机身仅上弦。可拖球、绳挂点和定位销。标签只在操作时显示。默认慢镜头：回转、离杯、飞行、首次落地；暂停、回放和时间轴不新增记录。主视图展示完整投射器、弹道和落点，下方展示完整弹道；卷尺每小格1 cm、每大格10 cm，落点指针按真实坐标放置。
- 近、中、远目标互斥单选，用户设置目标值，公差 ±15 cm，按首次落地判定。保存参数、重复确认、记录及 CSV 导出。
- 支持 2⁶ 全因子、2⁶⁻¹ 半分数（分辨率 VI）、可选中心点、球种交叉 CCF、iCCC/CCI 内接中心复合。无区组；分类因子没有中间水平。
- 回归提供编码方程、主效应及交互、按球种分层的曲率检验、纯误差、系数标准误和 P 值、残差图及拟合图。响应曲面为每种球分别拟合五个连续因子的完整二次方程。支持方程与检验 CSV 导出。

建议教学流程：先运行默认全因子＋中心点 → 检查曲率 → 点击「使用局部 iCCC 范围」并重新生成、运行 → 检查残差与独立验证 → 选择拟合建议设置 → 回到实验台独立验证。默认实验顺序随机化；每次重新生成都会消耗随机流，具体 P 值随样本改变，不预设显著性。

真实物理不是严格二次方程。宽范围的二次近似误差可能较大，应缩小范围；高 R² 不等于验证通过。检验依赖独立、方差齐性假设；CV 噪声可能异方差。数据只保存在当前页面内存，刷新前请导出 CSV。

## 验证

```sh
pip install -r tests/requirements.txt
python tests/test_physics.py
python tests/test_six_factor_doe.py
python tests/test_six_factor_interaction.py
python tests/test_tracking_tape.py
python tests/test_full_view_rearm.py
```

需要 Chromium（可用系统 `/usr/bin/chromium`）。物理测试使用独立 SciPy 积分；六因子测试覆盖全部设计、分类中心点、回归、P 值对照、发射、CSV 和移动布局。旧五因子版本的断言已由新测试替换，可从 Git 历史查阅。

[下载主分支 ZIP](https://github.com/Future2025shenzhen/AI-SPC/archive/refs/heads/main.zip)

本轮界面移除失拟检验与相关导出行，保留真实残差、R²、RMSE 和确认验证。不改写模拟数据或预设模型一定适用。球种控件只显示名称：乒乓球为光滑白色，高尔夫球为橙金色凹点表面；物理质量、半径和阻力参数仍按 PHYSICS_NOTES.md 计算。

最新外观与初始设置：B 释放角与 C 开火角均为100°，D 球杯高度420 mm。默认未上弦，先拖臂再松手发射。两种球均为白色，高尔夫球带灰白凹点。底座改浅金色，底脚附近绳路改浅灰蓝色。移除落地点的包围圈，仅保留卷尺下方读数指针；所有飞行与落点视图的目标公差显示为水平线，不画竖向色带。主页静止视窗扩展到760×480，使机构左移并保留极限臂角左侧余量。

释放角最大180°；灰色参考臂已移除。

最新重新上弦行为：每次点击按钮或机身，B释放角复位到C开火角（其他因子、历史和随机流保留），再拉臂发射。卷尺上绿色区域对应当前目标±15 cm，并非空中目标框。完整发射视野默认打开：同屏展示投射器、物理弹道与落点，按SVG实际宽高比等比例缩放；公共轴的屏幕高度固定在80%，无上下跟球平移。长射程会相应缩小画面以容纳全貌。
