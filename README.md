## 操作

- **直接拉动黄色投射臂，松手即发射**。不想立即发射时，取消“拖动黄色投射臂，松手即发射”。
- A 释放角 100–185°：沿外圆弧拖动，或使用大滑块、数字框和 ±1° 按钮。
- B 开火角度 90–110°：沿内圆弧拖动限位销，也可用滑块或输入框。
- C 球杯 200–300 mm、E 绳挂点 100–200 mm：沿臂拖动实际部件或对应字母调节点。
- D 定位销 100–200 mm：沿支架上下拖动。
- 调整限位 B 越过当前臂角时，臂随限位移动。A=B 表示尚未上弦，须继续向后拉臂才能发射。参数卡可聚焦到图中控件，方向键也能微调。
- 默认已上弦至 A=145°，B=100°，可以直接点击实验台顶部“发射小球”。

## 三目标竞赛

近、中、远目标默认 250 / 300 / 425 cm，可设置为 70–700 cm 内的递增数值。命中公差固定 **±15 cm，包含上下边界**。

探索发射和确认验证分别记录。确认验证默认连续 10 次，可改为 2–30 次；期间锁定参数和目标，也可在本发落地后停止。每个目标的成绩只统计最近一组同设置确认验证，旧目标与历史参数不会被覆盖。

可以观察动画落点、公差带、绿色命中圆点与红色未命中菱形，并导出逐发记录和验证汇总 CSV。

**70–700 cm 是目标可设置范围，实际射程不硬截断。** 未充分上弦、绳松弛或动力不足时会明确提示；有效射程过近或过远也如实显示。射程从离杯位置的地面垂直投影起算。

## DOE 教学

参考用户附件《001 投射器试验竞赛小结.ppt》的流程：

1. 课堂三因子 A / C / D，固定 B=110°、E=200 mm。
2. 2³ 全因子，角点重复 2 次，加 3 次中心点：19 次。
3. 表面中心设计再增加 6 个轴向点：25 次，拟合二次响应。
4. 分析主效应、交互作用与拟合残差指标，针对三个目标搜索建议设置。
5. 载入建议值，进行独立确认验证。预测命中不等于实际命中。

也保留五因子全因子与分辨率 V 半分数设计。无效发射不伪造响应或进入回归。正式 ANOVA、失拟与残差诊断可在 Minitab / JMP 中继续完成。

## 物理模型与参考网站

已通过浏览器实际操作 [SigmaZone 原站](https://www.sigmazone.com/catapult/)，验证部件拖动、限位联动、拉臂后松手发射及落地流程。

本程序按相同类型的黄色立臂、球杯、限位杆、销支架、弹力绳与底座关系**独立绘制**。不复制原站图片、商标或程序，不声称与其画面逐像素相同。

旧版的射程映射公式已删除。现在计算完整绳路的弹性势能、臂/杯/球惯量、重力矩与摩擦，再从实际离杯角速度计算含空气阻力的弹道。动画直接使用积分轨迹。模型参数及假设见 [PHYSICS_NOTES.md](PHYSICS_NOTES.md)，也可在程序教师模式中展开阅读。

这是明确假设下的教学模型，**不是原设备的标定数字孪生**。没有用原站某次落点反推或冒充真实材料参数。

所有数据仅保存在当前页面内存，刷新或关闭会清空，请及时导出 CSV。
