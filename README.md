# 投射器 × DOE 联动实验室

推荐入口：解压整个 ZIP 后打开 **DOE_Catapult_Analysis.html**。保留同目录的 **DOE_Catapult_Competition.html**，不要只复制一个文件。中文名称 **2K多响应变量DOE+投射器实验.html** 是同一 DOE 页面。图表库全部内置，计算不上传服务器。

若浏览器限制本地 `file://` 页面联动，可运行 `python start_lab.py`，会在本机 127.0.0.1 打开实验室，无需安装额外 Python 包或联网。

## 两条教学路线

1. 默认：X1 球种、X2 释放角、X3 定位销刻度，2³ 重复两轮，共 **16 次**。打开 DOE 页面后自动连接投射器并采集。球种只取乒乓球 / 高尔夫球，无分类中心点。
2. 选择第二条路线并创建：X1 球杯高度、X2 释放角、X3 定位销刻度，8 个角点＋3 个中心点，共 **11 次**。点击自动采集，检查曲率。
3. 点击“保留11次，追加6轴点 CCC”，在原数据上添加6个外接轴点，合计 **17 次**。α=8^(1/4)，所有默认轴点均在机械范围内。前11条响应和随机状态不改变。
4. 新增轴点默认标为阶段区组2，物理模型不人为施加阶段漂移。曲率与区组检验均根据数据计算，不强制显著或不显著。
5. 完成分析后，可用原 DOE 优化器寻找设置，点击“载入优化设置到投射器”，或做5次独立验证。验证发射保存在投射器记录中，**不加入训练行**。

默认 CV=0.5%，初始种子2026；内部及JSON实验包中，每行保存实际物理设置、采样前后随机状态及未取整的响应。运行顺序可随机化，不同随机顺序会改变噪声与设置的配对，所以P值会变化。没有为获得特定显著性筛选、重采样或修改响应。

## 双向继续分析

- DOE 页面内嵌同目录投射器。自动采集直接调用它的首次落地计算和发射记录，不使用回归方程反造响应。勾选“逐发显示慢镜头”可观看每次完整发射；未勾选时快速计算、记录同一物理结果。
- Catapult 上方的“链接 DOE · 继续分析数据”会打开 DOE 并传入当前联动实验、内部 DOE 计划或手动发射记录。有数据时不重新生成响应；无数据时创建默认16次路线。
- “导出联动实验包”保存 JSON，包含因子映射、固定条件、响应、阶段、种子、模型项和物理设置；用“导入实验包”恢复。通用 CSV 仍可用于 Minitab / JMP。
- 数据默认保存在页面内存，关闭或刷新前请导出。浏览器阻止弹窗时，请允许本地页面打开分析页，或使用实验包导入。

## 投射器表现与物理

主视图显示白色小球：高尔夫球有灰白凹点。不画蓝色实线轨迹；球在首次落地后反弹并离开，卷尺处保留 **80%透明（20%不透明）** 的球形落点印记。反弹是独立展示阶段，响应始终测量首次落地。

释放角 B 的范围100–180°；开火角 C 为90–120°；每次重新上弦令 B=C；球杯 D 默认420 mm；E 为0–200定位销刻度（1格=1.22 mm）；F 为100–200 mm绳挂点。A 为球种。内部物理设置数组顺序为 `[B,C,D,E,F,A]`，实验包用 `physicalIndex` 显式标明映射。

发射使用刚体、弹簧、重力、摩擦的 RK4 积分，飞行含重力和二次空气阻力。两种球的质量、半径和 Cd 不同。模型参数、假设与限制见 [PHYSICS_NOTES.md](PHYSICS_NOTES.md)。二次响应面是实验范围内的近似；高R²不能替代残差检查与独立验证。界面不展示失拟检验，不表示物理数据严格满足二次方程。

## 曲面与读尺显示修正

球种为分类因子，不能把乒乓球到高尔夫球当作连续数轴。曲面图和等高线图只选择连续因子作横纵轴，用“乒乓球／高尔夫球”选择器固定类别，消除类别归属切换造成的台阶。可点击“查看主效应平面”查看同一批数据的一阶拟合，或恢复交互／二次模型；真实交互作用仍可产生正常曲面，不改写响应来强制平面。

数据表、图表读数和工程CSV按一位小数显示，内部数值与JSON实验包保留原精度，P值和方程系数保留必要精度。球种在表格、CSV、因子水平、图例和优化结果中均显示实际名称。

落地后的球形印记保留在卷尺上（80%透明），并新增首次落点近景读尺，重新上弦后也保留，直到下一次落地或页面刷新。
